Schema deviation forced by reality (documented in learnings)
------------------------------------------------------------
The spec's morph marker 'App\Models\HostingAccount' and history actions
'assigned'/'override' were REJECTED by the existing DB CHECK constraints
(Laravel 13 compiles enum to varchar + CHECK on SQLite too — verified
empirically). An additive enum-widening migration was therefore required.
Also: ip_allocation_history has no created_at/updated_at columns, so the
model needed $timestamps = false, and changed_at had to be fillable.
ip_address_snapshot was widened VARCHAR(45) -> TEXT so the mandated
json_encode-of-the-row fits on MySQL strict mode.
