# Task 14 — Foundation amendment: permission-aware `queryFor` hook

Plan: `.omo/plans/global-search.md` (todo 14, lines 231-237; amendment note in `.omo/drafts/global-search.md` "Execution amendments", 2026-09-23)
Date: 2026-09-23
Environment: Windows, PowerShell 5.1, PHP 8.4.16, Laravel 13, PHPUnit 12.5.35
Test DB: sqlite `:memory:` (`phpunit.xml`); `Tests\TestCase::setUp()` seeds the real RBAC roles per test.

Why this amendment exists: todo 7's acceptance (a draft KB article must be invisible to a
`kb.view`-only user but visible to a `kb.edit` holder) cannot be met by the frozen
`query(string $term, int $limit)` interface, and the plan guardrails forbid `hasPermission()`
inside providers. The amendment is minimal and backward-compatible: a permission-aware
`queryFor()` on the contract, a `baseQueryFor()` hook on the base class, and one call swap in
`GlobalSearchService::groups()`.

## Files changed (in scope only)

- `app/Services/Search/SearchProvider.php` — added `queryFor(array $permissionNames, string $term, int $limit): Collection` + docblock
- `app/Services/Search/AbstractSearchProvider.php` — `query()` delegates to `queryFor([], ...)`; `queryFor()` owns the existing pipeline; new `protected baseQueryFor()` defaulting to `baseQuery()`
- `app/Services/Search/GlobalSearchService.php` — `groups()` calls `queryFor($permissionNames, ...)`
- `tests/Feature/GlobalSearchServiceTest.php` — 3 new tests + recording stub; existing 11 untouched

`applyTermFilter`, `applyRanking`, `whereLikeEscaped`, `resultRow`, `routeIsRegistered` and
`rankColumn` are unchanged (git diff below shows the pipeline body moved verbatim, only the
`$query = $this->baseQuery();` line became `$query = $this->baseQueryFor($permissionNames);`).

## Implementation notes

- `queryFor()` is the permission-aware scoping hook: the permission set is resolved ONCE by
  `GlobalSearchService::permissionNames()` and passed in; providers vary their base query by
  overriding `baseQueryFor()`; no provider calls `hasPermission()` (grep below: the only
  occurrences of the token in `app/Services/Search/*.php` are pre-existing docblock prose plus
  the new docblock's "providers must never call `hasPermission()`" line — zero calls).
- `query()` keeps its exact old behavior: `queryFor([], ...)` → `baseQueryFor([])` → `baseQuery()`.
  Every existing provider extends `AbstractSearchProvider` (checked), so all inherit the new
  concrete method; no implementor of the interface was left incomplete.
- `baseQueryFor()` default returns `baseQuery()`, so all 8 currently-created providers under
  `app/Services/Search/Providers/` are byte-for-byte unchanged in behavior.
